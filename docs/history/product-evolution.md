# 产品演进

## 当前基线

v1.0 是项目当前稳定基线：AI Test Auditor 以确定性、静态、仅源码的方式审计 JavaScript 与 TypeScript 测试；显式策略门禁只会因 `FAKE` 阻断。后续能力以[迭代计划](../zh/roadmap.md)为准，尚未交付的方向不构成当前承诺。

## 能力演进摘要

| 阶段      | 已形成的能力                                     | 对后续迭代的意义                                   |
| --------- | ------------------------------------------------ | -------------------------------------------------- |
| v0.1–v0.3 | AST 提取、确定性规则、CLI 和离线输入契约         | 静态发现必须可定位、可解释且可回归测试。           |
| v0.4–v0.5 | 变异证据输入、Unit/API/E2E 规则与变更文件选择    | 外部证据只作显式输入；规则扩展不等于运行时验证。   |
| v0.6–v0.9 | advisory policy、baseline、decision 和参考工作流 | 建议性上下文不能改写静态 finding、分类或退出语义。 |
| v1.0      | 显式 opt-in 的 `FAKE`-only gate                  | 仅确定性 `FAKE` 可阻断；`WEAK` 永不阻断。          |

## 保留的版本依赖

v1.0 建立在既有静态审计、严格输入快照和建议性上下文之上。它不执行被审计源码，也不将未标记测试推断为强测试。未来适配层必须兼容这些既有结论，而不是覆盖它们。
